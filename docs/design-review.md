최신 선택: 사용자는 작은 팬진 방향에서 회청색 `#F1F5F7`이 눈에 편하다고 평가하고 선택했다. A의 3열/모바일 2열, 굵은 로고, 게시일별 구분을 기준으로 이어간다. 종이빛/회청색/흰색은 같은 48개 자료로 1440/390px에서 비교했고 가로 넘침 없이 배경 전환을 확인했다. 선택은 DESIGN.md에 반영했다.

## 감성 방향 3안 비교

사용자 요청으로 선택된 A의 3열·원본 비율을 유지한 세 방향을 추가했다. `feed.html?layout=a&mood=album|archive|zine`에서만 비교 메뉴가 나타나며 기존 mood 없는 A 화면은 유지한다. 선택은 아직 미확정이다.

- 개인 사진집: 따뜻한 바탕, 로컬 Batang/serif 로고, 날짜와 작성자를 정돈한 정보 배치.
- 디지털 수집함: 하늘색 .zip 라벨, 수집함 탐색 바, 고정폭 날짜와 사진 장수 디테일.
- 작은 팬진: 굵은 로고, 게시일별 날짜 표제와 구분. 한국시간 게시일 기준이며 촬영일로 추정하지 않는다.

같은 저장본 48개로 1440/390px 6개 조합을 확인했다. 게시물 수·첫 게시물 동일, 가로 넘침 없음, 영상 필터 동작. 팬진은 6개 날짜 구분을 표시한다. 데스크톱 세 안과 모바일 사진집 스크린샷을 직접 검토했다. 스크린샷은 `.local/mood-{album,archive,zine}-{1440,390}.png`. 폰트 파일·미디어 다운로드·운영 배포는 수행하지 않았다. 로컬 폰트 존재에 따라 명조 모양은 기기별로 다를 수 있다.

## A안 비평 반영

사용자가 승인한 네 가지 정리 완료: 비교 바/감성 제목·문구 제거, 동일 작성자·발견 출처 중복 표시 제거, 화면 캡션의 그룹·멤버 반복 태그 및 중복 해시태그 정리, 마지막 저장 시각을 목록 상단으로 이동. 원문 캡션과 출처 데이터는 수정하지 않았다. 서로 다른 작성자/발견 출처는 모두 표시한다. 로컬 저장본이라는 설명을 푸터에 유지한다.

첫 사진 위치는 1440px에서 354→238px, 390px에서 404.5→276px. A의 열 수·이미지 폭·사진 비율·열 간격은 유지했다. 360/390/768/1440px 가로 넘침/최신순 확인, 필터·URL 복원·상태 패널 포커스·503 기존 목록 보존·이미지 실패 원문 링크 검증 통과. git diff --check 통과. 첫 캡처에서 이미지 페인트가 비어 보여 디코딩과 프레임 대기 후 재확인했다. 수정은 로컬 시안에만 반영했다.
