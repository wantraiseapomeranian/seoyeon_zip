## 기준선

배포 SHA·관찰 시작/종료 예정은 배포 확인 후 아래에 기록한다. 현재는 사전 기준선이다.

- D1 export: 2026-10-02 04:04 UTC. X 3,108 / Instagram 209 / YouTube 380건.
- Instagram 공개 사진 갱신 대상 33개, 표시 주소 매핑 60개. 이전 전체 이미지 검사 118장 중 117장 정상, 원문에서도 없는 1장은 미복구 상태를 유지한다.
- 갱신 시작은 UTC 하루 2회, 실행당 `maxTotalChargeUsd=0.05`, 배치 18개다. 설정상 최대 0.10 USD/일은 이 갱신 작업에만 적용한다. 기존 수집·Worker/D1·기타 작업의 총비용이나 실제 청구액이 아니다.
- YouTube 검색은 일일 50회 제한과 태평양 날짜 경계 재개를 사용한다. 검색 출처 3개 모두 마지막 오류 null, pages 0/cursor 없음. 마지막 성공은 2026-10-02 04:04:29/04:09:28/04:14:30 KST로, 10/1 16:00 KST 초기화 이후 정상 완료를 확인했다. 예약 영상의 공개 가능 전환은 별도 미관찰이다.
- X 404 재시도 코드가 존재하나 실제 3회 연속 404→자동 복구는 아직 미관찰이다.

## 기록 방법

| 대상 | 하루 기록 | 완료/주의 판단 |
|---|---|---|
| X | 마지막 성공 경과, 오류 종류, retry→정상, 수동 개입 수 | 실제 반복 404가 없으면 해당 분기 미관찰 |
| YouTube | 일별 검색/상세 호출, 성공 시각, pages/cursor 변화, 예약 영상 상태 | 후보 저장과 공개 판정을 구분 |
| Instagram 동기화 | 마지막 성공·오류·다음 예정 | 이미지 갱신 성공으로 대체하지 않음 |
| Instagram 이미지 | 성공/실패/기한 초과 건수, 다음 예정, 일별 시작 횟수, 제한된 공개 이미지 HEAD 상태 | 예산 대기 자체와 남아 있는 게시물 실패를 구분 |
| 비용 | Worker/D1 실제 사용량, Apify 기존 수집/갱신별 사용량, YouTube 호출 | 접근할 수 없는 실제 청구값은 null/미확인 |
| 알림 | 신규/지속/복구/중지, 실제 조치 여부, 수동 개입 | 불필요한 새 유료 실행 없이 원인부터 확인 |

기존 관리자 운영 상태·알림·일별 기록과 읽기 전용 SELECT를 사용한다. `x-review-v1` 기록에 피드 SQL 측정치를 섞지 않는다. raw 응답·토큰·서명 URL·개인정보는 공유 기록에 넣지 않는다. 관찰을 위해 운영 장애를 만들거나 유료 수집을 시작하지 않는다.
