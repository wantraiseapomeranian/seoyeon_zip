## 제안 (미구현)

1. 공식 소스에서는 실제 작성자가 triplescosmos인 직접 글과 재게시/인용을 별도 처리. 재게시·인용을 공식 직접 콘텐츠로 자동 승인하지 않는다.
2. 직접 글 + 미디어 + 정확한 멤버 태그(대소문자/NFKC 정규화)는 높은 신뢰도의 포함 후보. 그룹 태그만으로 통과시키지 않는다. 다른 멤버와 함께 태그된 글을 혼자 나온 사진으로 단정하지 않는다.
3. 멤버 태그가 없지만 이름 + 포토 비하인드 등 개인 콘텐츠 제목이 있는 직접 글은 별도 포함 후보/검토군. 단순 본문 이름만으로 포함하지 않는다.
4. Gravity 투표·결과, Objekt 판매/출시, 응모·판매 안내는 공지 판별을 별도로 거쳐야 한다. 넓은 단어 금지 목록으로 모든 '이벤트' 사진을 제외하지 않는다.
5. 공식 글의 분류는 official이 기본. COSMO 앱 링크/안내 문구만으로 cosmo 분류하지 않는다. 이름 판별, 공지 배제, 종류 분류를 분리한다.

추천 시작점은 1~2의 보수적 자동 포함과 3의 별도 검토. 이번 실제 콘텐츠 표본8/23·8/27은 현재 초기7일 범위 밖이다. 정책 적용과 과거 수집 범위 확대는 별개이며 공식 연결 직후 사진이 반드시 추가되는 것은 아니다.
