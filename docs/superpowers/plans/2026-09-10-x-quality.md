# X 피드 품질 정리

사용자 승인 범위: 숨김/복원, 사진 단위 중복, 안내·상품·캐릭터 검토, 원문 재확인. 원본 데이터는 삭제하지 않는다.

1. 독립 검토/원문 상태 및 이미지 fingerprint 테이블과 필터링 view. 재수집에도 수동 판단 보존.
2. 동일 원본 파일 바이트 SHA-256만 자동 중복 제거. 근접 dHash는 검토 후보만 제안. 각 글의 모든 사진을 개별 비교하며 다른 사진·영상은 보존.
3. 수집 시 안내·상품·캐릭터 문맥을 표시하고 기존 저장 데이터에도 적용. 소유자 전용 X 검토 화면에서 숨김/복원.
4. 별도 유지관리 cron은 한 장 fingerprint 및 한 원문 재조회씩 수행. 404는 숨김 후 재확인, 네트워크/429/5xx는 상태 변경 없음. 수집 중지 스위치를 존중.
5. 단위 테스트, workerd 빌드, 실제 중복 표본 및 사용자 지정 원문, 모바일 UI, 인증 차단 확인 후 GitHub 자동 비공개 배포.

사진 식별은 얼굴 인식이 아니다. 이미지 차이가 있는 재업로드는 자동 확정하지 않으며 사용자 검토가 필요하다.
