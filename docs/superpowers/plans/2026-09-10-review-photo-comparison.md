# 검토 사진 탐색과 비교

승인: 두 검토함 한장씩 사진 넘김, 원형 화살표/순서/스와이프/확대. X는 현재 사진과 후보를 나란히 표시하고 작성자/게시일/실제 피드 상태/원문을 제공. 같은 사진 묶기·다른 사진·현재 글 숨기기.

1. 다른 사진 쌍 저장 migration과 revision 보호. 후보 메타데이터 및 거절 후보 제외 회귀 테스트.
2. Instagram childPosts/images 정규화, 안전한 이미지 URL만 저장. 기존 판단 보존.
3. 공통 gallery 스크립트, X 사진-후보 동기화, 인스타 연결.
4. 브라우저 넘김/스와이프/확대/후보판단 및 모바일 확인. 비공개 migration→자동 배포. 기존 인스타 원본에서 사진 보충 가능 여부 확인.
