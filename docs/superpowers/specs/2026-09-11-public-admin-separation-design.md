# 방문자·관리자 기능 분리 설계

작성일: 2026-09-11. 상태: 사용자 승인으로 비공개 구현·검증 진행. 공개 전환 별도.

## 목적

방문자는 피드와 수집 진행 현황을 볼 수 있고, 실제 수집·자료·검토 조작은 소유자만 할 수 있게 한다. 별도 관리자 사이트나 회원가입은 만들지 않고 기존 Cloudflare Access 소유자 인증을 활용한다.

| 기능 | 방문자 | 관리자 |
|---|---|---|
| 피드·필터·사진 넘기기·원문 링크 | 허용 | 허용 |
| 수집 계정·진행 상태·마지막 성공 시각 | 허용 | 허용 |
| 수집 현황 새로고침 | 조회만 허용 | 조회만 허용 |
| 수집 중지·켜기·재시도 | 숨김, API 차단 | 허용 |
| 자료 관리·URL 등록·내보내기 | 숨김, API 차단 | 허용 |
| X·Instagram 검토함 | 숨김, 직접 접근 차단 | 허용 |
| 상세 오류·수집 내부 상태 | 미노출 | 기존 범위 유지 |

방문자 모달 제목은 **수집 현황**, 관리자 모달은 **수집 및 관리**로 한다. 방문자에게는 수집/자료 관리 탭 대신 수집 현황만 표시한다. 관리자 로그인 진입 링크는 허용하며 버튼들이 잠깐 보였다 사라지는 현상이 없어야 한다.

## 제약

- 기존 X 3분 수집 주기와 다른 Cron 예약을 유지한다.
- 데이터 삭제·cursor 초기화·수집 조건 변경을 하지 않는다.
- 기존 Cloudflare Access 소유자 인증을 유지한다.
- 공개 전환은 별도 사용자 승인 후 수행한다.
- 공개용 응답은 필드 허용 목록으로 구성하고 내부 객체를 그대로 반환하지 않는다.
- 관리자 권한은 매 요청 서버에서 확인하며 프런트엔드 표시 상태를 신뢰하지 않는다.

## 권한과 공개 경로

Worker의 `PUBLIC_FEED_ENABLED`가 정확히 `true`일 때만 명시된 공개 경로를 익명 조회에 연다. 기본값은 비공개다. 공개 대상은 피드 페이지(`/`, `/feed.html`, 표준 이동 대상 `/feed`)와 필요한 정적 파일, `GET /api/feed`, `GET /api/collection-status`, `GET /api/session`이다. 나머지 경로와 변경 메서드는 관리자 인증을 요구한다.

`/api/sources`는 기존 내부 상태와 revision을 반환하므로 관리자 전용으로 유지한다. `/api/samples`, `/api/export`, `/api/manual-posts`, `/api/admin/*`, 수집 변경·재시도 경로도 공개하지 않는다. 관리자 HTML 원본 경로와 확장자 없는 별칭도 같은 정책을 적용한다.

`/admin`은 Access 로그인 진입점이며 소유자 검증 성공 후 고정 경로 `/`로 이동한다. 공개 페이지에서도 관리자 세션을 인식하도록 서버가 Access JWT 헤더 또는 `CF_Authorization` 쿠키를 서명·issuer·audience·만료·소유자 이메일까지 검증한다. 토큰이 있는 잘못된 헤더를 무시하고 쿠키로 우회하지 않는다. 쿠키 전달 범위와 현재 Access 설정은 비공개 환경에서 확인해야 할 배포 조건이다. 브라우저는 토큰을 읽거나 저장하지 않는다.

`/api/session`은 `{role:"visitor"}` 또는 `{role:"owner"}`만 반환한다. 이메일·토큰을 반환하지 않는다. 역할 및 개인화 응답은 `private, no-store`로 유지한다. 설정 오류와 인증 장애 시 관리자 기능은 닫힌 상태를 유지한다.

## 공개 수집 현황

항목은 `source`, `state`, `lastSuccessAt` 세 필드로 한정한다. `state`는 `paused`, `waiting`, `ok`, `attention` 중 하나다. 전체 수집 봉인 또는 계정 비활성은 paused, 명시적인 실제 오류는 attention, 성공 기록 없음은 waiting, 나머지는 ok로 변환한다. 과거 페이지 상한 등 정상 종료 표식은 오류로 표시하지 않는다. 이번 범위에서는 시간 경과만으로 새로운 장애 판정 기준을 만들지 않는다.

마지막 성공 시각은 성공한 페이지 저장 시각이다. 전체 과거 자료 수집 완료를 의미하지 않는다. 현황 새로고침은 DB 조회만 수행하고 수집기를 실행하지 않는다. 오류 원문·revision·cursor·lease·예약 내부 정보는 공개 응답에서 제외한다.

피드도 표시용 필드만 반환한다. 숨김/보류 게시물과 그 게시물의 원문·계정이 같은 사진 출처 링크를 통해 노출되지 않는지 확인하고, 공개 가능 자료만 출처에 포함한다.

## 완료 기준

익명 세션은 피드와 수집 현황만 볼 수 있다. 소유자 세션은 기존 관리 기능을 사용할 수 있다. 비소유자·만료·위조 토큰은 관리 화면과 API에 접근하지 못한다. 직접 URL 접근과 버튼 강제 표시로도 권한을 우회할 수 없다. 모바일에서 빈 탭·빈 버튼 자리·관리자 버튼 노출이 없다. 이 결과를 비공개 검증 환경에서 확인한 뒤 별도로 공개 전환 여부를 결정한다.
